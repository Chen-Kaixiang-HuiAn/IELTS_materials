## 学习顺序建议

### 路线一：先走完主线，再补类型（推荐）

1. `Writing/Task2/Part1-主线题走通/主线题走通-从0到7.5.md` 一份文档按"路程"走完。
2. `Writing/Task1/Part1-线图走通/线图走通-从0到7.5.md` 一份文档按"路程"走完。
3. 打开 `Writing/Task2/Part2-摊开大饼/` 和 `Writing/Task1/Part2-摊开大饼/`，按自己的薄弱类型跳着看。
4. 写任何题目前，先查附录 A-D 找可用语料（A/D 为大作文、C/D 为小作文，均为真实范文语料库）。

### 路线二：哪里弱补哪里

- 题型拿不准 → 先看 `Writing/Task2/Part2-摊开大饼/按题型/`
- 话题没想法 → 先看 `Writing/Task2/Part2-摊开大饼/按话题/`
- 图表描述干巴巴 → 先看 `Writing/Task1/Part2-摊开大饼/` + 附录 C/D

## 这套教程的核心理念

1. **Process Writing（过程写作）**  
   高分不是「憋出来的」，而是改出来的。Part 1 会带着你：
   - 先「试水」写一版；
   - 再逐层思考「缺什么、加什么、怎么连」；
   - 最后打磨语言，逼近范文水平。

2. **类型化思维**  
   Part 2 把题目按题型/话题/图表类型摊开，让你每类都见过、写过、有套路。

3. **范文是终点，不是起点**  
   教程中引用了 `Writing-examples/` 里的真题范文作为「参考答案」，但重点不是背，而是看懂：
   - 作者为什么这样分组/分段？
   - 哪些地方值得迁移？
   - 哪些地方还能改得更好？
   所有被引用的范文，在 Part 1 / Part 2 里都贴出（题目 + 双语范文），不藏路径，方便直接对照。

4. **附录就是弹药库**  
   附录 A-D 尽量多收语料，写的时候直接翻，写多了自然内化成自己的。

## 使用提示

- 每个 Part 1 文件都有 **「你自己先写」** 的环节，不要跳过。
- 每个 Part 2 文件都按 Part 1 的主线程流程讲解（破题→推因果链→试水→润色→完整范文），范文**整篇贴出**，无需跳去别处对照。
- F 系列图片在 `Writing-examples/Task1_img/F-01.png`、`F-02.png`、`F-03.png`，属**非数据类表格题**（题干因原始资料丢失未收录，故无范文），教程中对 F 系列自主行文讲解，用来练「看图破题」。
- 教程中的图片引用路径统一为 `../../../../Writing-examples/Task1_img/...`，请在支持相对路径的 Markdown 阅读器中查看。
