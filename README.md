# IELTS Materials

个人雅思备考资料库。内容按题型和科目分类存放，方便日常复习、整理和回看。

## 目录结构

```
IELTS_materials/
├── Listening-audios/      # 听力音频（mp3）
├── Speaking-answers/      # 口语参考答案
│   ├── Speaking_Part1_Answers.md
│   ├── Speaking_Part2_Answers.md
│   └── Speaking_Part3_Answers.md
├── Tutorials/             # 备考教程与笔记
│   └── Writing/           # 写作专项教程
├── Writing-examples/      # 写作练习样例（按日期命名）
│   ├── Task1_img/         # Task 1 配图
│   └── Writing-YYYY-MM-DD.md
├── MD_Standard.md         # Markdown 排版样式模板
└── README.md
```

## 各部分说明

- **Listening-audios**：听力练习音频，配合题目使用。
- **Speaking-answers**：口语三个 Part 的参考答案，可按话题背诵、改写和套用。
- **Tutorials**：写作相关的系统教程与技巧笔记，适合集中学习打基础。
- **Writing-examples**：每周写作练习存档，文件名带日期（如 `Writing-2025-08-23.md`），便于追踪进步；`Task1_img` 存放 Task 1 对应的图表图片。
- **MD_Standard.md**：Markdown 文档的统一排版样式（标题字号、分页等），新写文档时可直接套用。

## 使用建议

1. 复习写作时，按日期顺序打开 `Writing-examples`，对比早期与近期内容，找薄弱环节。
2. 练口语前先看 `Speaking-answers` 对应 Part，用自己的话复述而非硬背。
3. 需要系统补基础时，优先看 `Tutorials/Writing`。

> 资料持续更新中，保持练习节奏最重要。
